## О проекте:

Я писал сайт на чистом HTML/CSS/JS, и попытался привести код к более понятной файловой структуре, разделив 
ответственность CSS и JS по разным файлам. 

Так же я видел очень много возможностей для реализации компонентного подхода, динамического рендеринга, реактивность и прочих возможностей, которые
дают фреймворки. В парадигме Vue можно было использовать множество директив для управление рендерингом и динамическим отображением данных. Естественно,
это всё можно реализовать и на чистом HTML/JS, но из-за ограничения времени не было возможности. 

От себя добавил:
-слайдер изображений, так как посчитал его уместным при наличии более 1 фото товара;
-обновил кнопку корзины, теперь можно сразу регулировать, сколько единиц товара добавлять;
-ховер эффекты на кнопки +/- для корзины;
-резиновая адаптивная верстка по моему вкусу.

  
##  Структура проекта

```

│

│
```
